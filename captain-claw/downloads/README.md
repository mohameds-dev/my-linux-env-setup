# Manual Downloads Staging

Place manual downloads here before running `install.sh`:

- **`CLAW.FEC`** (~349 MB): In-game animated cutscenes.
  - Download from: [MediaFire](https://www.mediafire.com/file/9yfncm88b9pjewk/CLAW.FEC)
  - Drop file here as `CLAW.FEC` (or into `~/games/captain-claw/game/CLAW.FEC`).

*(Base game `CLAW-1.4.5.4.zip` does not need manual download; `install.sh` downloads it automatically into `~/games/captain-claw/game`.)*
